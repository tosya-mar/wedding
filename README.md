# Ваня & Тося — сайт-приглашение

Свадьба 15 августа 2027, Санкт-Петербург. Vue 3 + TypeScript + CSS, сборка Vite.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + сборка в dist/
```

## Что внутри

- 26 дизайнов с переключателем внизу экрана. Выбранный дизайн сохраняется и попадает в адрес (`?theme=...`).
  - Классические: `garden`, `sage`, `petersburg`, `mono`, `silk`, `nights`, `peony`.
  - Интерактивные, с заставкой перед приглашением (лежат в `src/components/intros/`):
    - конверты: `envelope` (сургуч), `ribbon` (развязать бант), `petals` (квадратный конверт-лепестки);
    - разводные мосты: `bridge` (Дворцовый мост, фонари), `dawn` (пастельный, ползунок), `sails` (алые паруса и салют),
      `meet` (жених и невеста идут навстречу), `lineart` (золотой контур), `papercut` (бумажная аппликация с параллаксом),
      `blueprint` (чертёж с рычагом и шестерёнками), `garland` (мост в цветах, половины опускаются по отдельности);
    - для программистов: `terminal` (янтарный терминал), `ide` (редактор кода, кнопка Run), `git` (pull request и слияние веток),
      `pixel` (8-битная игра), `matrix` (цифровой дождь);
    - сердца: `heart` (удерживать, пока наполнится), `halves` (соединить половинки), `lock` (замок любви и ключ в Неву).
- Обратный отсчёт до 15.08.2027 15:20 (МСК).
- Анкета гостя: присутствие, количество человек, спутники, напитки, комментарий.
- Анимации (появление при прокрутке, лепестки/звёзды, конверт) и кнопка их отключения ✦.
  По умолчанию анимации выключены, если в системе включено «уменьшение движения».

## Где менять тексты

- `src/data/wedding.ts` — имена, дата, место регистрации и банкета, программа дня, пожелания, варианты напитков.
- `src/data/themes.ts` — список дизайнов и палитры дресс-кода для каждого.
- `src/styles/themes.css` — цвета, шрифты и детали оформления каждой темы.

## Отправка анкеты на почту

Анкета отправляется через бесплатный сервис [FormSubmit](https://formsubmit.co) на `marikyan.tosya@mail.ru`.
При **первой** отправке FormSubmit пришлёт на эту почту письмо со ссылкой «Activate Form» — нужно один раз
её нажать, после этого ответы гостей будут приходить письмами с таблицей. Если отправка не удалась,
гостю показывается ссылка, открывающая готовое письмо в почтовом клиенте.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует его при каждом пуше в `main`.
Один раз в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
